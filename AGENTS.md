Цель: портировать имеющиеся `RXPGuides v4.10.2` и `RXP Leveling 1.0.0` на клиент из `project.json`. Общайся по-русски, кратко.

В новом чате прочитай `docs/context/STATE.md`, затем выполни `git status --short --branch` и `git log --oneline -5`. При изменённом дереве читай только diff затронутых файлов. Код и Git имеют приоритет над STATE.

Главный агент самостоятельно делегирует изолированный поиск, долгие проверки и независимое ревью. Короткую последовательную работу выполняет сам. Передавай подагентам минимальный task brief без истории чата; дешёвую модель используй для механики, Sol для реализации, Astra только для сложной архитектуры/диагностики или критичного ревью. Подагенты не коммитят, не делают push и не устанавливают аддон; главный агент проверяет и объединяет результат.

Постоянные правила:

- Установка разрешена только в `D:\Games\World of Warcraft Sirus для тестов`.

- `main` хранит исходный контрольный импорт. Порт ведётся в `port/sirus-3.3.5`.
- Не переписывай исходники массово. Сначала совместимость и минимальная загрузка, затем функциональные модули.
