# Аудит порта RXPGuides для Sirus

Цель: клиент Sirus build 12340 / Interface 30300 и контент до WotLK.

## Источник данных

Снимок `D:/Poslevkusie/data/snapshots/2026-09-07-test-client` содержит:

- 331 549 записей о функциях, вызовах и XML-обработчиках;
- 3 014 кандидатов нативных функций из бинарников;
- 1 448 вариантов извлечённых файлов;
- 1 423 зависимости между файлами;
- восстановленный FrameXML, SharedXML и документацию API Sirus.

`python tools/sirus_api_audit.py` сверяет исполняемый Lua-код RXPGuides с этой
базой. Читаемый индекс записывается в `docs/SIRUS_API_AUDIT.md`, подробный JSON
с доказательствами и файлами использования — в `.local/sirus-api-contracts.json`.

Текущий результат:

- 481 ссылка подтверждена извлечённым Lua/XML;
- 102 API предоставляет наш compatibility-слой;
- 9 имён подтверждены только бинарным индексом;
- 118 ссылок требуют ручной классификации или проверки в игре.

Ручные выводы по критическим подсистемам находятся в
`docs/SIRUS_API_CONTRACTS.md`. Наличие имени не доказывает совместимость
сигнатуры или поведения.

## Обязательный порядок

1. Найти API в `SIRUS_API_AUDIT.md`.
2. Открыть указанную реализацию в снимке и проверить параметры/returns.
3. Зафиксировать важное отличие в `SIRUS_API_CONTRACTS.md`.
4. Исправить общий адаптер, а не отдельные callers.
5. Выполнить Lua/runtime-проверки и проверить новую сессию в игре.

## Подтверждённые решения

- Quest ID берётся из девятого результата `GetQuestLogTitle`.
- Отсутствующий `GetQuestLogIndexByID` возвращает ноль значений.
- Таймеры Sirus имеют несовместимую colon-сигнатуру и изолированы адаптером.
- Неймплейты используют документированные `C_NamePlate` и события Sirus.
- UI сохраняет оригинальные RestedXP assets; отсутствующие методы фреймов
  адаптируются на границе 3.3.5.
- Runtime-локали ограничены enUS и ruRU.
