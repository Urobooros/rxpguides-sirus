# Аудит порта RXPGuides для Sirus

Цель: только клиент Sirus build 12340 / Interface 30300 и контент до WotLK.

## Автоматическая проверка

Запуск: `python tools/port_analysis.py`.

Отчёт `.local/port-analysis.json` строится из исходников RXP и базы API
`D:/Poslevkusie/data/snapshots/2026-09-07-test-client/index/api.sqlite`.
Он разделяет файлы по клиентам, находит ветки проверки версии и сверяет ссылки
на API с извлечёнными Lua/XML определениями и кандидатами из бинарников.

Текущее состояние после первой очистки:

- 80 общих Lua-файлов требуют дальнейшей проверки по веткам;
- 5 Lua-файлов базы относятся непосредственно к WotLK;
- файлов из каталогов других клиентов не осталось;
- найдено 9 общих файлов с проверками версии клиента;
- 50 ссылок на API наблюдались в извлечённом Lua/XML Sirus;
- 884 ссылки имеют только более слабое подтверждение из бинарного индекса;
- 198 ссылок пока не сопоставлены и требуют адаптера, удаления ветки или проверки в игре.

Имя API в базе не доказывает совместимость сигнатуры. Расширения Sirus, включая
API неймплейтов, считаются доступными только при наличии определения в снимке и
после проверки поведения в игре.

## Принятые решения

- Удалены TOC, базы, библиотеки и гайды, загружаемые только Retail, MoP, Cata,
  Vanilla и Season of Discovery.
- TBC и Survival-маршруты восстановлены по решению владельца проекта. Они
  являются дополнительным контентом для WotLK: TBC доходит до 70 уровня,
  Survival до 60 уровня. Полного маршрута до 80 среди них нет.
- Из локализаций оставлены английская база строк и русский перевод.
- Сохранены общие маршруты Азерота и Запределья: они нужны персонажам WotLK на
  уровнях 1–70 и не являются поддержкой другого клиента.
- Сохранены только таблицы талантов WotLK.
- `RXP Leveling` пока не очищается автоматически: его файлы 31–85 смешивают
  WotLK и Cata, поэтому сначала потребуется отделить диапазон 31–80.
- Современный набор настроечных библиотек заменяется согласованными версиями из
  установленного и работающего на Sirus аддона Details.

## Следующая очистка

Каждая из 9 общих версионных веток проверяется вручную. Ветки выше WotLK
удаляются вместе с вызываемыми только ими функциями. Общий код сохраняется,
если он используется WotLK или расширением Sirus.
