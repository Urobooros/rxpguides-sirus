# RXPGuides для Sirus 3.3.5

Приватная рабочая копия для переноса двух аддонов из тестового клиента:

- `RXPGuides v4.10.2` — движок RestedXP;
- `RXP Leveling 1.0.0` — отдельный набор маршрутов, зависящий от RXPGuides.

`main` содержит исходный импорт без адаптации (`8925b3a`). Работа ведётся в `port/sirus-3.3.5`. Текущий статус находится в [docs/context/STATE.md](docs/context/STATE.md), порядок работ — в [docs/PLAN.md](docs/PLAN.md).

Целевой клиент: `D:\Games\World of Warcraft Sirus для тестов`. Пока порт не прошёл этап установки, исходные RXP в игре не изменяются.

RXPGuides содержит `LICENSE` CC BY-NC-SA 4.0 и лицензии встроенных библиотек. В `RXP Leveling` отдельная лицензия не обнаружена, поэтому этот репозиторий должен оставаться приватным.
